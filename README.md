# UI-UX-Experiment4

## Aim:
To design a wireframe diagram for a generic application or website


## Algorithm:
1. Display Welcome Screen.
2. User clicks "Get Started".
3. Display Login/Signup Screen.
4. User enters login details.
5. Validate user information.
6. Display Home/Dashboard Screen.
7. User searches or selects a product category.
8. Display Product Listing Screen.
9. User selects a product and adds it to the cart.
10. Display Checkout Screen.
11. User enters delivery and payment details.
12. User clicks "Place Order".
13. Display Order Confirmation message.
